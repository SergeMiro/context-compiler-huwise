## Freshness

The portal's data changes (yearly rentrée updates, directory edits). Expected values are recomputed by
`golden_refresh`; each eval run stores the card versions it used (`EvalRun.card_versions`) and its commit
(`metrics.commit`). A count recorded on 11.11.2026 (e.g. 23 collèges in Dijon) may differ later: the page shows the
date of every recording, and the live button re-runs the query.

## Equivalence rules for scoring

- numeric answers: a number in the answer within the tolerance of the expected value (5 % for counts by default,
  1 % for averages/sums of the v2 set); numbers copied from the question do not count;
- text answers: the expected label appears in the answer (accent- and case-insensitive);
- no-data questions: an explicit "pas de données"-type answer;
- counts are scored on the value, the filters are checked by the reference query (not by the agent's text).
