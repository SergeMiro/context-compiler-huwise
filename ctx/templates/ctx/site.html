Même question, deux systèmes

Un serveur MCP générique donne à l'agent l'accès à tout le catalogue. Ce qui lui manque, c'est le contexte : sur ce portail, la Côte-d'Or s'écrit de trois façons — '021', '21' et "COTE D'OR".

« Combien de collèges publics y a-t-il en Côte-d'Or ? »

Serveur MCP générique sans contexte

  1. search_assets — recherche BM25 sur les titres
  2. get_asset — schéma brut : code_departement · text, aucun exemple de valeur
  3. L'agent devine : code_departement = '21'
0 ligne → réponse fausse0

Context Compiler fiches compilées

  1. find_dataset — BM25 + usage réel des agents : l'annuaire en tête
  2. explain_dataset — la fiche montre code_departement (e.g. '021')
  3. query validée : code_departement = '021'
réponse exacte, vérifiée sur l'API58

Les pièges du portail

Écrire 30 requêtes de référence à la main a échoué 11 fois au premier essai — exactement sur ces pièges. Les fiches les rendent visibles.

Un département, trois formats

code_departement='21' → 0 ligne
code_departement='021' → 58

Annuaire : '021', jeux IPS : '21', libellé : "COTE D'OR".

Années stockées en dates

session='2025' → erreur de type
year(session)=2025

Neuf jeux stockent l'année en date. La fiche donne le filtre pour chaque champ date.

Nombres stockés en texte

avg(ips) → erreur (IPS écoles)
ips · double (IPS collèges)

order_by ips_etab desc trie comme des chaînes. La fiche affiche le type réel.

Casse différente

libelle_academie='DIJON' → 0
libelle_academie='Dijon'

Les jeux IPS et bac écrivent 'DIJON', l'annuaire 'Dijon'.

Apostrophe dans une valeur

departement='COTE-D''OR' → syntaxe
departement="COTE D'OR"

L'échappement SQL n'existe pas en ODSQL : guillemets doubles.

Champ qui commence par un chiffre

sum(2ndes_gt_filles) → syntaxe
sum(`2ndes_gt_filles`)

Accents graves obligatoires. Et pas de DISTINCT : on liste avec group_by.

À quoi ressemble une fiche

La fiche courte que renvoie find_dataset pour l'annuaire, version {{ card.version }}. Compilée de façon déterministe depuis MariaDB : nouvelle version seulement si le texte change.

fr-en-annuaire-education · courte · {{ card.tokens_short }} jetons
{{ card.short }}
Ce que c'est, en une phrase

Titre, description coupée, volume, fraîcheur, licence, producteur.

Clés de jointure avec leur vrai format

code_departement (e.g. '059') : l'agent voit les trois chiffres. Neo4j relie les jeux qui partagent ces clés.

Types et indications

Champ date → filtre year(…) ; limites de l'API ; codes en texte avec zéros initiaux.

Pas de données personnelles

Les champs mail, telephone, adresse… n'ont jamais d'exemples de valeurs.

De 1 à 5 000 portails

Rien ne change dans le code : taille de base, nombre de workers, routage Elasticsearch, cache.

Données~750 000 jeux · ~15 M champs

MariaDB, index (portail, modified) et (jeu, nom).

Scan1 requête par scan complet

Celery sur RabbitMQ, portails étalés sur l'heure, un verrou par portail, ≤ 5 % du quota API quotidien.

Rechercheun seul index

routing + filter par portail : isolation et vitesse.

Graphelinéaire en clés

(:Dataset)-[:HAS_KEY]->(:Key) : 79 arêtes au lieu de 3 081 pour uai.

Chemin chaud1 requête ES + cache

Serveur MCP sans état, mise à l'échelle horizontale.

LLMhors ligne uniquement

Budget quotidien par portail, jamais sur le chemin d'une requête d'agent.

Isolation des portails dans chaque requête : MariaDB, ES, Neo4j — avec tests
La clé API du client (X-Apikey) est transmise, jamais stockée ni journalisée
ODSQL en liste blanche : vrais noms de champs, limit ≤ 100, pas de commentaires
Champs personnels sans exemples, jamais envoyés au LLM
Limite de débit par portail (serveur) et par IP (proxy)
Le journal ToolCall garde l'outil, la latence et le code d'erreur — jamais la question
