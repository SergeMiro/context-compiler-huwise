Pourquoi c'est mieux

Les trois erreurs qui reviennent dans les transcriptions de l'agent générique, et ce que fait Context Compiler à la place.

Il trouve le bon jeu

La recherche tient compte de ce que les agents utilisent vraiment : le portail publie le journal de son propre serveur MCP (39 675 appels).

génériquene trouve pas l'annuaire (son titre ne dit ni « lycée » ni « école »), prend un autre jeu : 0 ligne
context compilerl'annuaire en 1re place : c'est le jeu le plus utilisé

Il connaît le format

La fiche montre les vraies valeurs. Ici la Côte-d'Or s'écrit '021', '21' ou "COTE D'OR" selon le jeu, et les années sont des dates.

génériquerentree_scolaire = '2025' → refusé : c'est une date
context compileryear(rentree_scolaire) = 2025 → 80 217 élèves

Il ne devine pas

Chaque requête est vérifiée contre le vrai schéma avant d'atteindre le portail. Une erreur ne coûte ni quota ni étape à l'aveugle.

génériquedepartement = '21' part telle quelle vers le portail
context compiler« champ inconnu ; proches : code_departement »

Les idées d'Andrej Karpathy, appliquées

Le projet est construit sur quatre idées qu'il a formulées en 2025–2026.

Context engineering · 2025

Le bon contexte, au bon moment

« the delicate art and science of filling the context window with just the right information for the next step »

Ici →d'abord une fiche courte (≤ 400 jetons) pour choisir ; la fiche complète seulement pour le jeu choisi.
Software 3.0 · 2025

Construire pour les agents

Les agents sont un nouveau type d'utilisateur : la documentation doit être lisible par un LLM, en markdown, avec un llms.txt.

Ici →llms.txt et {{ pages }} pages markdown générés pour le portail, plus un serveur MCP.
autoresearch · 2026

Essayer, mesurer, garder le meilleur

L'agent tente une modification, lance l'expérience et ne la garde que si la métrique s'améliore ; sinon il revient en arrière.

Ici →le LLM propose une modification de fiche ; l'éval sur 30 questions décide : gardée ou annulée.
Software 3.0 · 2025

Génération ↔ vérification

L'IA génère vite, l'humain vérifie vite ; un curseur d'autonomie règle ce qu'on lui laisse.

Ici →deux modes, « proposer » ou « auto » ; l'humain relit le diff dans l'admin Django.

Et l'esprit nanoGPT : la boucle de l'agent tient en une centaine de lignes, sans framework.
